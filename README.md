# 🏛️ 记忆宫殿智能复习中枢

把「记忆宫殿」和「间隔重复」合起来用的一个单文件网页应用。
上传一张自己画或自己拍的宫殿地图，在图上点出每个桩点的位置，之后它会按遗忘曲线提醒你回来做提取练习。

**在线试用：** https://rapids2.github.io/memory-palace/

无需注册、无需后端、没有任何外部依赖（不加载 CDN、不加载网络字体、不调任何 API）。
所有数据只存在你自己的浏览器里。

---

## 这是解决什么问题的

记忆宫殿法（method of loci）的原理是：人对**空间**的记忆远强于对**孤立符号**的记忆。
把要背的词挂到一条熟悉路线的固定位置上——门口的伞架、第三级台阶、窗台的花盆——
回忆时沿着路线走一遍，词就跟着位置一起被拽出来。

但这个方法有两个实践上的坑：

1. **桩点会糊。** 光在脑子里想，路线过几天就模糊了，得有一张图把它钉死。
2. **建完就忘了复习。** 宫殿只是编码手段，长期记忆还是得靠按时重复提取。

这个应用就是补这两块：**图上标桩点** + **到点提醒你回来做遮挡测试**。

## 功能

**地图与桩点**

- 上传宫殿地图图片，在图上逐个点击标定桩点坐标
- 桩点单词按 `01. word (联想场景)` 的格式整段粘贴录入，自动解析
- 地图可缩放、拖拽、一键适应窗口

**三种遮挡模式**（提取练习的核心）

| 模式 | 看得到 | 要你回想 |
|---|---|---|
| 遮单词 | 联想场景 | 单词是什么 |
| 遮场景 | 单词 | 挂在哪、什么画面 |
| 全显 | 全部 | —（对答案 / 初次熟悉用） |

**自适应间隔重复**

初次录入后按这个节奏提醒复习：

```
20 分钟 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天
```

答错的桩点可以打「🚩 生疏标记」，之后能**只看生疏**单独刷；
生疏项会加权拉高整座地图的复习频率。当场遗忘的会在 10 分钟后重测。

**提醒与备份**

- 到期时桌面通知 + 标签页标题角标 `(N)`
- 一键导出完整备份（含地图图片）或仅元数据 JSON
- 导入时按「最后复习时间」逐条比对合并，旧备份不会盖掉新进度
- 超过 7 天没导出会在顶部提醒

**当 App 装**

支持 PWA。手机浏览器打开后「添加到主屏幕」，就是独立窗口 + 图标 + 无地址栏。

## 上手三步

1. 左栏「➕ 录入新地图」→ 起个名字（如 `大地图01-科技艺术博览馆`）→ 传图
2. 把单词整段粘进去，一行一个：

   ```
   01. abolish (公牛撞毁旧法条)
   02. abortion (急停胚胎光柱)
   03. above (金色箭头顶端白鸽)
   ```

3. 点「📍 标定桩点坐标」，按顺序在图上点出每个词的位置 → 存入宫殿

之后这座地图就进入复习队列了，到期自动提醒。

## 数据在哪、隐私怎么说

**服务器上没有你的任何数据**，因为压根没有服务器逻辑——它只是一个静态 HTML 文件。

- 文字与进度 → 浏览器 `localStorage`
- 地图图片 → 浏览器 `IndexedDB`

由此带来两个后果，用之前请知道：

- **不跨设备同步。** 手机和电脑是两份独立数据，靠导出/导入备份搬家。
- **网址就是数据的身份证。** 浏览器按域名隔离存储，换托管平台、改仓库名、加自定义域名，
  都等于开了一个全新的空应用。**动网址之前先导出备份。**

清浏览器数据、重装系统、换设备都可能让本地存储消失，所以建议养成每周导一次备份丢网盘的习惯。

## 自己部署

整个应用就是这几个文件，扔到任意静态托管上即可：

| 文件 | 说明 |
|---|---|
| `index.html` | 应用本体，HTML / CSS / JS 全在里面 |
| `manifest.webmanifest` | PWA 清单，让手机能「添加到主屏幕」 |
| `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` | 图标 |

**GitHub Pages**：Fork 或下载本仓库 → `Settings` → `Pages` → Source 选
`Deploy from a branch` → `main` + `/ (root)` → Save，等 1–2 分钟出网址。

**Cloudflare Pages / Netlify**：直接把文件夹拖进去 Upload assets 即可，不需要 Git。
想加访问密码可以在 Cloudflare Access 里设白名单邮箱（免费额度 50 用户）。

> **别直接双击本地文件用。** `file://` 协议下 Chrome 通常禁用 IndexedDB，
> 地图图片功能会直接失效，桌面通知也需要安全上下文。走 HTTPS 托管这两项才稳定。

更新版本只要覆盖 `index.html` 重新提交，域名没变 = 存储没变，数据不受影响。
提交后仍看到旧版就按 `Ctrl + F5` 强制刷新。

## 已知限制

- 不跨设备自动同步（要做到得上后端）
- 间隔重复的调度单位是**整座地图**，靠生疏标记加权，而不是每个单词独立排程
- 桌面通知只在页面开着时才发；标题栏的 `(N)` 角标是更可靠的提醒
- 仅在桌面 Chrome / Edge 与移动版 Safari / Chrome 上实测过
